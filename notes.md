# Gig-Tracker Demo Notes

This file contains design thoughts, ideas, and future plans for the full version of Gig-Tracker.

## Design Notes

- The demo schema is intentionally simplified.
- Full production version includes:
  - Additional tables
  - Stored procedures
  - Automated calculations
  - Data validation logic
  - Import/export features

## Future Enhancements

- GUI interface (Python or web-based)
- Multi-platform analytics
- Tax estimation tools
- Mileage tracking improvements
- CSV import/export
- Dashboard with charts

## Why This Demo Exists

To showcase SQL and database design skills without exposing proprietary logic.
