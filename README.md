# Gig-Tracker (Demo Version)

This is a simplified demonstration of a MySQL-based tracking system designed to help gig workers organize income, expenses, mileage, and platform activity. 

The purpose of this demo is to showcase:
- Database design
- SQL fundamentals
- Reporting logic
- Clean project structure
- GitHub version control

⚠️ Note: This is a **demo version**.  
The full production schema, stored procedures, automation logic, and advanced features are intentionally excluded to protect future commercial potential.

---

## Features (Demo Version)

- MySQL schema with platforms, gigs, and optional tagging
- Sample data for testing
- Example queries for summaries and reporting
- Clean, modular SQL files
- Safe for public sharing

---

## Tech Used

- MySQL
- SQL joins, constraints, indexing
- GitHub for version control
- Future GUI planned (Python or web-based)

## File Overview

- `schema_demo.sql` — Creates the demo database and tables
- `sample_data.sql` — Inserts safe example data
- `sample_queries.sql` — Demonstrates reporting queries
- `notes.md` — Design thoughts and future plans
